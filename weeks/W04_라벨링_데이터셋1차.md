## 이번 주의 핵심 — 여기서 틀리면 나머지 11주가 무의미해진다

```
기준시점 T = 사업보고서 접수일자
라벨      = T < 사건일 <= T + 365일
```

`사건일 > T` 를 등호 없이 강제한다. 감사의견은 그 사업보고서 안에 들어 있으므로
등호를 허용하면 그 보고서로 그 의견을 맞히는 동어반복이 된다 (`docs/01` 부록 A-1).

## 감사의견 '불명' 5.6% 를 어떻게 볼 것인가 (2026-09-03 실측)

`adt_opinion` 이 빈 값인 기업-연도가 **1,175건 / 20,668건 = 5.6%** 다.
`labels.classify_opinion()` 이 이를 `불명`으로 따로 둔다. 조용히 '적정'으로 처리하면
모르는 것을 정상이라고 라벨링하는 것이고, 놓친 사건을 영영 모르게 된다.

- [x] 불명은 **초기 연도에 극심하게 몰려 있다** (2015년 44.4% → 2022년 2.0%)
- [x] 민감도 (a) 0.347 vs (b) 0.332 — CI 겹침. **(a) 현행 유지**
- [x] 불명 1.35% vs 판정있음 2.36% — **오히려 낮다.** 우려와 반대 방향

**쏠려 있으면 그 자체가 결과다.** 재무제표를 제때 못 내는 상태와 부실은 무관하지 않다.

## 민감도로 반드시 같이 볼 것
- 창 365 / 400 / 450일에서 사건 수가 각각 몇 건인가
- 제출 간격이 365일을 넘어 라벨을 놓친 기업-연도가 몇 건인가
- 이 손실이 특정 기업군에 쏠려 있는가 ← **쏠려 있으면 그게 결과다**

### 쏠림을 재는 방법이 생겼다 (2026-09-03)

`pipeline.label_loss_by_extension()` 을 돌린다.

3주차 수집 중에 **「사업보고서제출기한연장신고서」 394건(298개사, 전체 기업-연도의 1.39%)**
을 확보했다. 제출기한을 연장했다는 건 감사가 예정대로 안 끝났다는 뜻이다.
그리고 연장한 기업은 다음 보고서까지 간격이 길어져 **12개월 창을 넘길 후보 1순위**다.

| 확인할 것 | 의미 |
|---|---|
| 연장 기업의 창 초과율 vs 비연장 기업 | 차이가 크면 라벨 손실은 무작위가 아니다 |
| 창 초과 건 중 실제 사건 비율 | 놓친 사건이 부실 기업에 쏠렸는지 |

- [x] **완료 (2026-09-04)**: 연장 없음 33.2% vs 연장 있음 **79.8%** — 2.4배
- [x] **주 분석 창을 400일로 상향** (`HORIZON_DAYS = 400`). 365·450 은 민감도로 병행
- [ ] 면담에서 확정 (`docs/03` 안건 6번)

이 표가 "12개월이라는 흔한 설정이 국내 상장사에서 무엇을 잃는가"에 대한 답이 된다.

## 결측·이상치 처리 기준 (확정안)
| 항목 | 기준 |
|---|---|
| 분모 0 | 비율을 0이 아니라 **NaN**으로 둔다 |
| 결측 대치 | 학습 구간 중앙값. **동시에 `_결측` 더미를 추가** — 결측 자체가 신호일 수 있다 |
| 이상치 | 학습 구간 1/99 분위 윈저라이즈. 절단이 아니라 클리핑 |
| 기준값 산출 구간 | **학습 구간만.** 전체에서 계산하면 미래 정보가 샌다 |
| 제외 | 금융업(KSIC 64~66), 스팩·리츠, 비12월결산 |

## 추가 발견 — 2026년 공시분은 우측 절단

사건비율이 2025년 3.40% → 2026년 1.17% 로 급락한다. 실제가 아니라 **관측이 덜 된 것**이다.
창 400일이면 2026년 3월 공시분의 관측 기간은 2027-04 까지인데 아직 오지 않았다.
분할 정의상 자동으로 빠지지만 관측치 2,479건이 놀고 있다. 보고서에 명시한다.
