# W11 (11/10~11/16) — 설명 카드 생성 · 설명 충실도 정량 검증

상태: 준비 완료 / 실행 대기
변경: "블라인드 평가용 사례 10건 선정 및 평가 도구 제작"을 대체 (인터뷰 제외에 따른 재설계)

## 사람이 검증하지 않는다면 무엇이 검증인가

설명이 실무자에게 납득되는지는 이제 물어볼 수 없다. 대신 **설명이 모델을 정직하게
반영하는지**는 물어볼 수 있다. 이건 코드로 확인 가능하고, XAI에서 충실도(faithfulness)라 부른다.

납득 가능성과 충실도는 다른 것이다. 이 축소를 보고서에 명시한다.

## 할 일
- [x] 검증 구간 카드 생성 (평가 구간은 최종 1회 원칙상 열지 않음)
- [x] **삭제 검사 통과** — k=1 에서 0.2119 하락 (무작위 0.0091, 23.3배)
- [x] 무작위 대조 — 모든 k 에서 SHAP 상위가 크게 앞섬
- [x] 안정성 필터 적용 (W09, 기준을 한 번 고침)
- [x] 정합성 — 상위 12개 중 불일치 1개(영업이익률, 공선성)
- [x] 모순 23.8% → **변화량 변수를 카드에서 제외해 14.1%**. 12주차 재료로 목록화

## 마지막 항목이 이 주의 수확이다

카드는 묶음(위험을 높인/낮춘)을 SHAP 부호로, 문장을 관측값으로 정한다.
그래서 "매출이 줄었습니다"가 *위험을 낮춘 요인* 밑에 나오는 일이 생긴다.
이건 버그가 아니라 모델이 실제로 그렇게 판단했다는 뜻이고, 감추면 안 된다.
이런 사례를 모아 12주차 오분류 분석의 입구로 쓴다.
