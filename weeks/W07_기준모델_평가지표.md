## 평가 지표 체계 (확정)

| 지표 | 쓰는 이유 |
|---|---|
| PR-AUC | 사건 비율 2% 환경의 주 지표. **기준선 = 사건 비율** 을 항상 같이 표기 |
| ROC-AUC | 보조. 불균형에서 낙관적으로 보이므로 단독 인용 금지 |
| 재현율@정밀도0.3 / 0.5 | 실무 언어. "오탐 2건을 감수하면 몇 건 잡나" |
| Brier | 확률 보정 확인. 설명 카드에 확률을 쓰므로 필요 |
| 부트스트랩 95% CI | 사건 수가 적어 점추정만으로는 아무 말도 할 수 없다 |

**정확도(Accuracy)는 보고하지 않는다.** 전부 정상으로 찍어도 98%가 나온다.
`tests/test_smoke.py::test_metrics_are_not_accuracy` 가 이 원칙을 코드로 붙잡는다.

## 반복 관측의 표준오차 (Shumway 2001)

같은 기업의 2019년과 2020년 재무제표는 독립이 아니다. 그런데 로지스틱은 모든 행을
독립으로 보고 표준오차를 계산한다. 그러면 **계수가 실제보다 유의해 보인다.**

Shumway(2001)는 기업-연도 패널을 쓰는 모형(= 우리 설계)에서 이 문제를 지적하고,
검정통계량을 기업당 평균 관측 연수로 나누는 보정을 제안한다.

- [x] 기업당 평균 5.91년 (13,547/2,294)
- [x] 재산출 완료 → `results/w07/계수_군집보정.csv`
- [x] **18개 → 11개.** 7개가 유의성을 잃었다 — 정상이다

성능 지표(PR-AUC)는 이 보정과 무관하다. 영향받는 것은 "어느 변수가 유의한가"뿐이다.
그런데 그 문장이 보고서에 들어가므로 보정 없이 쓰면 틀린 말이 된다.
