## 수집 대상 — 실측으로 확정 (2026-09-03)

`corp_codes()` 는 stock_code 보유 기업을 **3,988개** 준다. 폐지 종목이 섞여 있다.
그대로 돌면 **호출의 절반이 빈 응답에 쓰인다** (표본 100사 × 2년에서 응답률 49%).

그래서 `dart.universe()` 로 대상을 좁혔다 — 정기공시 상세유형 A001(사업보고서)로
실제 제출 기업만 추리고 상장사와 교집합을 잡는다.

| | 2024년 기준 |
|---|---|
| corp_codes (stock_code 보유) | 3,988 |
| 사업보고서 제출 (전체) | 3,177 |
| **상장 & 제출 (수집 대상)** | **2,769** |
| 제출했으나 비상장 (외감 등) | 408 |

기업-연도 단위로 실제 제출한 건만 호출하므로 빈 응답이 없다.

> **함정**: `list.json` 은 `corp_code` 없이 조회하면 **검색기간이 3개월로 제한**된다(status 100).
> 긴 구간을 그냥 넣으면 에러가 난다. `disclosures_all` 이 분기로 잘라 돈다.
> 회생절차 공시 수집도 같은 함수를 쓰므로 함께 고쳐졌다.

> `data/cache/` 를 지우면 며칠치 할당량이 날아간다. 백업 없이 지우지 말 것.

## KRX 시세는 별개 경로다

DART 할당량과 무관하다. pykrx로 종목당 한 번씩 받아 캐시한다.
2,500종목 × 약 0.5초면 30~40분. DART 수집이 도는 동안 같이 돌려도 된다.

> **2026-09-02 확인**: pykrx에서 `get_market_ohlcv`(일별 시세)만 살아 있다.

> 시가총액은 종가 × 발행주식총수로, 시장수익률은 표본 전체 동일가중 수익률로 만든다.
> **지수를 쓰지 못한 것은 한계로 명시한다.**

## 감사의견은 자유 텍스트다 (2026-09-03 실측, 20,668건)

`adt_opinion` 은 코드값이 아니라 사람이 쓴 문자열이다. 실제 분포:

```
적정 14,332 / 적정의견 3,958 / (빈 값) 1,175 / 의견거절 387 / 한정 32
한정의견 25 / 적정(공정) 49 / 공정 38 / 거절 14 / 예외사항없음 13 ...
109건은 감사보고서 문단 전체가 통째로 들어온다
```

- **`거절` 단독 표기 18건**을 `의견거절` 키워드로는 못 잡는다 → 키워드 추가
- **`부적정` 은 `적정` 을 부분문자열로 포함**한다 → 비적정을 반드시 먼저 판정
- 긴 텍스트 109건에서 '적정'으로 시작하는데 비적정 키워드가 섞인 오탐: **0건** (확인함)
- **빈 값 5.6%** → `불명` 으로 분류. 4주차에 민감도로 처리

## 뜻밖의 소득 — 강조사항이 같은 응답에 들어 있다

`accnutAdtorNmNdAdtOpinion` 응답에 감사의견만 있는 게 아니었다.

| 필드 | 내용 |
|---|---|
| `emphs_matter` | **강조사항** — 계속기업 불확실성이 여기 적힌다 |
| `core_adt_matter` | 핵심감사사항 |
| `adt_reprt_spcmnt_matter` | 감사보고서 특기사항 |

12~13주차에 사업보고서 원문을 열어 읽으려던 것들이다. **정형 텍스트로 이미 온다.**
추가 호출도 없다(같은 응답). `labels.audit_matters()` 로 적재하고,
`계속기업불확실성` 플래그를 키워드로 만든다.

시점 정합도 자동으로 맞는다 — 이 항목들은 그 사업연도 보고서에 실리므로
기준시점 T 가 재무제표와 같다. `(corp_code, bsns_year)` 로 붙이면 끝이다.

> **주의**: 그래서 이건 **피처로 쓸 때 T 이전 보고서 것만** 써야 한다.
> 같은 보고서의 강조사항으로 같은 보고서의 감사의견을 맞히면 A-1 과 같은 동어반복이다.

## 함정 하나 더 — 감사의견 응답은 3행이다

이 API 는 **당기·전기·전전기 3개 행을 같은 `rcept_no` 로** 돌려준다.
전부 사건으로 세면 과거 의견이 나중 보고서 접수일에 다시 잡히는 **유령 사건**이 생긴다.
`labels.current_period()` 가 '당기' 행 하나만 고른다.
서식이 `제55기\n(당기)`, `제76기 (당기)`, `제75기(당기)` 로 제각각이라 공백을 지우고 판정한다.
