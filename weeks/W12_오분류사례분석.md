# W12 (11/17~11/23) — 오분류 사례 분석 (미탐·오탐)

상태: 준비 완료 / 실행 대기
변경: "실무자 인터뷰 및 블라인드 평가 1~3차"를 대체

## 사례 선정
평가 구간에서 다음을 뽑는다.

| 구분 | 건수 | 정의 |
|---|---|---|
| 미탐 | 8 | 실제 사건 · 모델 확률 하위 |
| 오탐 | 8 | 실제 정상 · 모델 확률 상위 |
| 정탐 | 4 | 대조군 |

## 사례마다 따질 것

```
모델이 본 것    : SHAP 상위 변수와 그 값
실제로 벌어진 일 : 사건 유형(감사의견/회생), 사건일, 직전 3개년 궤적
재무제표에 있었나: 있었다면 왜 모델이 못 봤나 (변수 부재 / 비선형 / 표본 부족)
                 없었다면 어디에 있었나 (주석 / 사업보고서 본문 / 어디에도 없음)
```

세 번째 줄이 핵심이다. **미탐이 변수 설계 문제인지 데이터 한계인지**를 가른다.
전자면 고칠 수 있고, 후자면 그게 결론이다.

## 감사인이 남긴 텍스트를 먼저 본다
3주차에 적재해 둔 강조사항·핵심감사사항·특기사항(`labels.audit_matters`)을 사례마다 읽는다.
API 로 정형 취득되므로 원문 열람은 여기서 안 잡히는 것만 한다.
- 직전 보고서 강조사항에 계속기업 불확실성이 있었는가 — **있었다면 모델만 못 본 것이다**
- 핵심감사사항이 무엇을 지목했는가
- 감사인이 바뀌었는가
- (원문 열람) 주요사항보고서 이력, 차입금 만기 구조 주석

**이 정보들은 공시에 있지만 27개 재무비율에는 없다.** 무엇이 있었는지 목록화하는 것이
이번 주의 실질 산출물이고, 13주차 결론의 재료다.
