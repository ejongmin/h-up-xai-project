## 1. 심사 의견서·내부 보고에 그대로 들어갈 수준인가

**결론: 아직은 아닙니다.** 표현보다 큰 문제가 먼저 있습니다.

### 1-1. 가장 심각: 문장이 사실과 틀릴 수 있습니다

`_risky_side()` 는 **표본 중앙값**보다 나쁘면 위험 문장을 고릅니다.
그런데 일부 문장은 "중앙값보다 낮다"가 아니라 **절대적 사실**을 주장합니다.

| 변수 | 위험 문장 | 문장이 참인 조건 | 현재 판정 기준 | 틀리는 예 |
|---|---|---|---|---|
| 순이익률 | "순손실 상태입니다" | 값 < 0 | 값 < 중앙값 | +1% (중앙값 +2%) → "순손실" |
| 영업이익률 | "본업에서 이익이 나지 않고 있습니다" | 값 < 0 | 값 < 중앙값 | +2% → "이익이 안 남" |
| 이자보상배율 | "이자비용을 감당하지 못하고 있습니다" | 값 < 1 | 값 < 중앙값 (원본 1.519) | 1.3배 → "감당 못함" (실제로는 감당 중) |
| 유동비율 | "…현금화 가능한 자산이 부족합니다" | 값 < 100% | 값 < 중앙값 | 120% → "부족" |
| 영업현금흐름_매출 | "현금이 들어오지 않고 있습니다" | 값 < 0 | 값 < 중앙값 | 소폭 양(+)의 OCF → "안 들어옴" |
| 자본잠식률 | "자본잠식이 진행되어 있습니다" | 값 > 0 | 값 > 중앙값 (**−829.7%**) | −500% (잠식 전혀 없음) → "잠식 진행" |

자본잠식률은 `CF_TARGET` 주석에 중앙값이 −829.7% 로 적혀 있어서,
**자본잠식이 전혀 없는 기업 상당수가 "자본잠식이 진행되어 있습니다"를 받을 수 있습니다.**
실무자가 이런 문장을 한 번이라도 보면 카드 전체의 신뢰가 무너집니다.

**제안 — 절대 기준이 있는 변수는 3단계로 나눕니다.**

```python
# 절대 기준선: 이 선을 넘으면 '사실' 문장, 중앙값과의 사이면 '상대' 문장
ABS_CUT = {
    "순이익률": 0.0, "영업이익률": 0.0, "영업현금흐름_매출": 0.0,
    "영업현금흐름_부채": 0.0, "자본잠식률": 0.0,
    "이자보상배율": 1.0, "유동비율": 1.0,
}

def _sentence(name, v, ref, risky, safe, label):
    """절대 기준을 넘으면 사실 문장, 중앙값보다만 나쁘면 상대 문장."""
    side = _risky_side(name, v, ref)
    if side is None or not side:
        return safe
    cut = ABS_CUT.get(name)
    if cut is None:
        return risky
    beyond = v > cut if name in HIGH_IS_RISKY else v < cut
    word = "높음" if name in HIGH_IS_RISKY else "낮음"
    return risky if beyond else f"{label} 표본 중앙값 대비 {word}"
```

> **주의**: `faithful()` 도 `_risky_side()` 를 쓰므로, 이걸 바꾸면 문장–관측값 모순률
> (현재 14.1%)이 달라집니다. 11주차 충실도 수치를 다시 뽑아야 합니다.

### 1-2. 숫자에 비교 기준이 없습니다

"유동비율 66.0%"만으로는 좋은지 나쁜지 판단할 수 없습니다.
실무 문서는 거의 항상 **기준값을 옆에 적습니다**. `card()` 에는 이미 `ref`
(학습구간 중앙값)가 넘어오므로 출력만 바꾸면 됩니다.

```
현재:  1년 내 갚아야 할 돈에 비해 … 부족합니다 (실측 66.0%)
제안:  유동비율 66.0% — 유동부채가 유동자산 초과 (표본 중앙값 ○○.○%)
```

"실측"이라는 단어는 실무에서 쓰지 않습니다. 지표명 + 값이면 충분합니다.

### 1-3. 카드 안에서 서로 모순되는 문장

예시 카드에 **"자본잠식 정도가 큽니다"(위험)** 와 **"자기자본이 두텁습니다"(안전)** 가 동시에 나옵니다.
산술적으로는 가능합니다(자산이 작으면 자본잠식 상태에서도 자기자본비율이 높을 수 있음).
하지만 읽는 사람에게는 명백한 모순으로 보입니다.

자기자본비율이 높다는 건 정확히는 "자본이 두껍다"가 아니라 **"부채 의존도가 낮다"** 입니다.

- 자기자본비율 안전 쪽 문장을 "부채 의존도 낮음"으로 변경
- `자본잠식 == 1` 이면 뒤에 "(단, 자본잠식 상태)" 부기

### 1-4. 같은 사실을 여러 번 말합니다

ROA · 순이익률 · 영업손실 · 2년연속영업손실이 모두 "적자"를 말하고,
자본잠식 · 자본잠식률도 겹칩니다. 위험 요인 4칸 중 3칸이 "손실"이면 정보가 줄어듭니다.

### 1-5. 문장별 수정 제안

심사 의견서·내부 보고서는 보통 **개조식(~임, ~함, 명사형)** 으로 씁니다.
"~습니다"는 고객 안내문 문체입니다.

| 변수 | 현재 위험 문장 | 제안 | 이유 |
|---|---|---|---|
| 부채비율 | 부채비율이 높습니다 (단위 **배**) | 부채비율 350.2% — 과다 | 국내 실무·한국은행 통계 모두 **%** 표기. `Δ부채비율` 은 이미 %p 라 수준만 배로 쓰면 불일치 → `PCT` 에 추가 |
| 이자보상배율 | 영업이익으로 이자비용을 감당하지 못하고 있습니다 | 이자보상배율(금융원가 기준) 0.8배 — 영업이익으로 금융비용 미충당 | 분모가 이자비용이 아니라 `ifrs-full_FinanceCosts` (할 일 2번 주의사항). 정의를 문장에 밝혀야 함 |
| 영업현금흐름_부채 | …**차입금** 상환이 어렵습니다 | 부채 대비 영업현금흐름 부족 | 분모가 차입금이 아니라 부채총계 |
| 영업현금흐름_매출 | 매출은 있으나 현금이 들어오지 않고 있습니다 | 매출 대비 영업현금흐름 부족(음수) | 영업현금흐름은 매출 회수만이 아님 |
| 자본잠식률 | 자본잠식이 진행되어 있습니다 | 부분 자본잠식 — 자본잠식률 52.0% (관리종목 사유 기준 50% 초과) | 유가증권·코스닥 모두 자본잠식률 50% 이상이 관리종목 지정 사유. 규정 기준을 붙이면 바로 읽힘 (정확한 조문은 상장규정으로 확인 권장) |
| 자기자본비율 (안전) | 자기자본이 두텁습니다 | 자기자본비율 71.0% — 부채 의존도 낮음 | 1-3 참고 |
| 유동비율 | 1년 내 갚아야 할 돈에 비해… | 유동비율 66.0% — 유동부채가 유동자산 초과 | "갚아야 할 돈" 같은 구어체 제거 |
| 로그자산 | 자산 규모가 작아 외부 충격이나 자금경색에 견딜 여력이 작습니다 | 자산 약 850억원 — 표본 하위권 | 인과 설명은 데이터가 보여준 것 이상 (2번 참고) |

### 1-6. 반사실 문구

`cf_target()` 이 `f"{name}이(가) 표본 중앙값(...) 수준이면"` 을 만들어서
**변수명과 "이(가)"가 그대로** 나옵니다 ("ROA이(가)", "로그자산이(가)").
한글 라벨 사전(`LABEL`)과 받침에 따른 조사 처리를 따로 두면 해결됩니다.

```python
def _josa(word, pair=("이", "가")):
    ch = word[-1]
    if "가" <= ch <= "힣":
        return pair[0] if (ord(ch) - 0xAC00) % 28 else pair[1]
    return pair[0]   # 영문 약어(ROA 등)는 라벨 사전에서 한글로 바꾸는 편이 안전
```

## 2. "규모가 작다"를 위험 요인으로 써도 되는가

**써도 됩니다. 다만 위치와 용도를 구분해야 합니다.**

규모는 부실예측의 표준 변수입니다. Ohlson(1980) O-score 에 총자산 로그가 들어가고,
우리가 이미 인용하는 Shumway(2001)도 상대 규모를 씁니다.
국내 신용평가사 방법론에도 사업규모가 평가 요소로 들어갑니다.
"근거 없는 요인"이라고 반박당할 가능성은 낮습니다.

다만 문제가 세 가지 있습니다.

| 문제 | 설명 | 제안 |
|---|---|---|
| 통제 불가능 | 수익성·유동성은 "개선하면 된다"가 성립하지만 규모는 아님 | 위험 요인 목록이 아니라 **별도 "기업 특성(참고)" 줄**로 분리 |
| 반사실이 무의미 | 현재 코드는 로그자산도 반사실 대상이라 "자산이 중앙값 수준이면 확률 ↓" 같은 문장이 나올 수 있음 | `counterfactual()` 의 `skip` 에 `"로그자산"` 추가 |
| 14배는 교란 가능성 | 부실 정의의 주축이 **감사의견 비적정**인데, 소규모 기업은 감사 환경 자체가 달라 비적정이 더 잦을 수 있음. 5.66% vs 0.41% 에 재무 부실 외 요인이 섞였을 가능성 | 발표에서 "규모 효과의 일부는 감사 환경 차이일 수 있음"을 한계로 명시 |

## 3. 확률을 소수점까지 보여줄 것인가

**등급(또는 구간) + 참고용 확률 범위를 권합니다.**

| 방식 | 장점 | 단점 |
|---|---|---|
| 27.3% | 정보량 최대 | 사건 150건으로 소수점 첫째 자리 정밀도는 근거가 없음. 코드 주석에 보정본 57.7% vs 비보정 89.8% 사례가 있을 만큼 보정 방식에 따라 크게 움직임 |
| 구간 (20~30%) | 불확실성을 정직하게 표현 | 경계 근처 기업은 작은 차이로 칸이 바뀜 |
| 등급 (5단계 중 5) | 신용등급에 익숙한 실무자에게 자연스러움 | 등급 경계를 검증구간에서 정하고 고정해야 함 |

**기준율도 함께 적는 것을 권합니다.** 전체 사건률이 약 0.65% (150 / 23,084)인데
> **(이종민 주, 2026-10-10)** 150 은 평가 구간 사건 수입니다. 전체 사건률은 2.30%(532/23,084), 평가 구간 3.12%, 검증 구간 2.54%.
"27.3%"만 보면 낮아 보일 수도 있습니다. "표본 평균의 약 40배"나 "검증구간 상위 1%"처럼
적으면 크기가 바로 읽힙니다.

## 4. 적용 후 카드 예시

중앙값은 자리표시(○)입니다. 값은 문서 예시 카드의 실측값을 환산했습니다.

```
부실위험 등급: 5 / 5  (검증구간 상위 1% · 추정확률 20~30% · 표본 평균 0.65%)

위험 요인
  - 부분 자본잠식: 자본잠식률 52.0% (관리종목 사유 기준 50% 초과)
  - 수익성: ROA -15.0% 적자 (표본 중앙값 ○.○%)
  - 유동성: 유동비율 66.0% — 유동부채가 유동자산 초과
위험 완화 요인
  - 자기자본비율 71.0% — 부채 의존도 낮음 (단, 자본잠식 상태)
기업 특성(참고)
  - 자산 약 3,900억원 — 표본 상위권
```
