## 2-1. 공시 단위 오류 수정 (2026-10-10~11) — `results/data_fix/단위수정_내역.csv`

업종별 합산비율을 만들다 발견했다 — 자산 **약 5경 원**(GDP 의 20배)짜리 기업-연도 하나가 업종 ROA 를 −32% 로 만들었다.
원인은 수집이나 변환이 아니라 **DART 가 돌려준 값 자체**였다(같은 응답의 자산·부채·자본이 모두 같은 배율, 항등식은 성립).

**판정 기준** (`features.fix_units`, 기준은 docs/13 §2 · §8-4 — **T 시점에 있는 공시만** 쓴다):
같은 회계연도 자산총계는 그 해 보고서 당기와 다음 해 보고서 전기로 두 번 공시된다.
자기 시계열에서 10³·10⁶ 점프가 있고 **이번 보고서의 전기 금액이 같은 배율을 확인**할 때만 단위 오류로 보고 정확히 10ᵏ 로 고친다.
(10-11 판은 다음 해 보고서로도 확인했으나 T 이후 정보라 10-13 에 뺐다. 확인되지 않는 점프는 그 해만 결측 — 해당 0건.)
비율은 같은 보고서 안에서 단위가 상쇄되므로 바꾸지 않는다. 고치는 것은 금액·로그자산·증가율뿐이다.

| 처리 (데이터셋 안) | 기업 | 기업-연도 |
|---|---|---|
| 확인된 단위 오류 수정 — 10³ (천원 단위 공시) | 2 | 10 (한 회사는 7년 연속) |
| 확인된 단위 오류 수정 — 10⁻³ · 10⁻⁶ (부풀린 공시) | 5 | 5 |
| 자산 10억 원 미만 — 확인할 공시가 없어 로그자산만 결측 | 12 | 74 |
| 빈 재무제표(자산 0) — 재무 변수 전체 결측 | — | 0 으로 채워진 응답에서 "영업손실 아님" 같은 거짓 이진 변수가 나오던 것을 막음 |

빌드 과정에서 판정 기준을 세 번 보완했다(모델 결과를 보기 전, docs/13 §2 보완 기록):
재작성이 겹친 전환(±1% 로는 놓침), 당기 값만 틀린 보고서, 단위 오류와 실제 성장이 겹친 해.

**한계**: 처음부터 끝까지 다른 단위로 공시한 회사는 전환이 없어 확인할 수 없다 — 위 18사가 그 후보이며 로그자산만 결측으로 두었다.
**성능 영향**: 수정 전후 같은 설정으로 비교하면 검증 PR-AUC 차이는 ±0.01 이내다. 로그자산은 학습 구간 1/99 윈저라이즈로 잘리고 있었다.

**정정본 재무 (docs/13 §8-3)** — DART 재무제표 API 는 최신 정정본만 준다. 재무 데이터의 실제 접수일이 T 보다 늦은 행이
**4,949행(21.4%)**, 그중 사건 195건이다. 원본 값을 받을 수 없어 고치지 못하고, 이 행을 뺀 결과를 **민감도**로 병기한다(§3 · §3-1).

### 개정 2 — '실측'이 실측이 아니었다 (중요)

### 개정 3 — 완전자본잠식 기업에서 부호가 뒤집혀 읽혔다 (심각)

자본총계가 음(-)이면 부채비율 = 부채/자본 도 음수가 된다. 그 값을 중앙값과 비교하니
카드가 **"부채비율이 낮은 편입니다"**라고 썼다 — 가장 심한 부실 신호를 안전 신호로 뒤집은 것이다.

→ 자본 기반 비율(부채비율·자기자본비율·자본잠식률)은 자본이 음수일 때 카드에서 제외하고,
대신 사실을 직접 적는다.

```
※ 자본총계가 음(-)입니다(완전 자본잠식).
  부채비율·자기자본비율은 해석할 수 없어 아래에서 제외했습니다.
```

`test_card_handles_negative_equity` 가 이 조건을 고정한다.

### 개정 4 — '위험을 낮춘 요인'이 늘 비어 있었다

카드 후보로 **기여도 상위 10개만** 넘기고 있었다. 그 10개는 위험 상위 기업에서

```
  - 자산 대비 영업이익이 부족합니다 (실측 -15.9%)
  - 자기자본이 얇아 손실을 흡수할 여력이 작습니다 (실측 1.3%)
위험을 낮춘 요인
  - 해당 없음 (안정 변수 중 위험을 낮춘 항목이 없습니다)
무엇이 달라지면 (모형 기준 — 인과 효과가 아닙니다)
  - ROA가 표본 중앙값(2.0%) 수준이면 부실확률 55.5% → 19.3%
  - 순이익률이 표본 중앙값(2.4%) 수준이면 부실확률 55.5% → 21.5%
  - 자본잠식이 해소되면 부실확률 55.5% → 23.0%
```

낮춘 요인이 없으면 조용히 빼지 않고 **"해당 없음"이라고 적는다**(원칙 ②). 반사실은 카드 확률과 같은 보정 모형으로 계산하며 인과가 아니다.

### 설명 카드에 반사실 추가

카드가 **왜 위험한지만** 말하고 **무엇을 보면 되는지**는 말하지 않았다.
여신심사에서 쓰이려면 후자가 필요하다.

```
무엇이 달라지면 (모형 기준 — 인과 효과가 아닙니다)
  - 총자산영업이익률이 표본 중앙값(3.0%) 수준이면 부실확률 22.1% → 8.4%   (현재 출력 예)
  - 유동비율이 표본 중앙값(161.9%) 수준이면 부실확률 22.1% → 8.8%
```

붙이면서 세 가지를 고쳤다.
- **모형을 섞고 있었다.** 카드 확률은 보정본, 반사실은 비보정이라 57.7% 와 89.8% 가 따로 놀았다
- **자본잠식률 목표를 '표본 중앙값(−829.7%)'으로 제시했다.** 자본잠식은 중앙값이 아니라
  **해소(0%)** 가 기준이다. 변수별 목표를 `CF_TARGET` 에 따로 뒀다
- **1.9%p 하락도 싣고 있었다.** 5%p 미만은 보여줄 값이 없어 제외한다

> 인과 효과가 아니라 **모형이 그렇게 반응한다**는 서술임을 카드 문구에 명시했다.

- (2026-10-10) 바꿀 수 없는 규모(로그자산)는 반사실로 제시하지 않는다(`explain.NO_CF`, 정민재 검토). 조사도 "ROA가"처럼 고쳤다.

## 3-14. 관리종목 사유 판정 (2026-09-28, 정민재) — `data/manual/kind_events.csv`

보류 48건은 Y/N 으로 밀어넣지 않고 **별도 범주로 남겼다** — 횡령·배임 24,

### 내가 의심했다가 기각된 것

`시장조치(복합)` 348건이 **전부 Y** 인 것이 서식 키워드 때문일 것으로 봤다.

본문을 표본으로 확인하니 **틀린 의심이었다.**
`내부결산시점 관리종목 지정 또는 상장폐지 사유 발생` 은 **재무요건 전용 공시**로,
본문 전체가 자산총계·부채총계·매출액·손익구조 표다. 비재무 사유 버전이 없는 서식이다.
→ 전수 Y 가 타당하다.

> 부수 확인: `corp_name` 은 corp_codes 의 **현재 사명**이고 공시 본문은 당시 사명이다
> (스마트솔루션즈 ↔ 에디슨EV, 대산F&B ↔ MP그룹). 원문 대조 시 혼동할 수 있으니 적어둔다.
