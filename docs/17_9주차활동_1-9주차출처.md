# 9주차 활동 기록 및 1~9주차 참고문헌·자료 출처

## 1. 9주차 활동 기록 — 보고서 삽입용

**활동 주제: SHAP을 활용한 변수 기여도 분석 및 중간 점검 보고회 자료 준비**

부실예측 모델이 어떤 재무정보를 근거로 기업의 위험을 판단하는지 확인하기 위해 SHAP을 적용하였다. SHAP은 개별 재무변수가 모델의 예측을 높이거나 낮추는 데 기여한 정도를 설명하는 방법이다(Lundberg & Lee, 2017). 전체 표본에서 영향이 큰 변수와 개별 기업의 위험 판단에 영향을 준 변수를 구분하여 분석하고, 수익성·자본구조 등 재무적 의미와 연결해 해석하였다.

설명의 일관성을 확인하기 위해 학습 시드를 바꿔 변수 기여도의 방향이 유지되는지 점검하였다. 또한 SHAP의 방향을 기준 모델인 로지스틱 회귀의 계수 방향과 대조하여, 두 분석이 다르게 나타나는 항목을 검토하였다. 방향이 일치한다는 사실만으로 설명이 옳다고 단정하지 않았으며, SHAP은 실제 부실의 원인을 증명하는 값이 아니라 모델의 예측을 설명하는 값이라는 점을 구분하였다.

기업별 예측 결과를 비전문가도 이해할 수 있도록 주요 위험 요인과 공시 재무비율을 함께 제시하는 설명 카드 초안을 작성하였다. 재무정보는 금융감독원 DART·OpenDART에서 수집한 자료를 활용하였고, SHAP 계산에는 관련 소프트웨어를 사용하였다(금융감독원, DART·OpenDART; SHAP 공식 문서). 설명 문장이 실제 재무 상태를 과장하거나 잘못 전달하지 않도록, 변수의 의미와 표현을 검토하고 향후 검사·보류 기준을 보완할 항목을 정리하였다.

마지막으로 연구 질문, 데이터 구성, 모델 평가 결과, SHAP 분석과 설명 카드 사례를 연결하여 중간 점검 보고회 자료를 준비하였다. 예측 성능과 설명의 신뢰성을 별도로 평가해야 한다는 점, 과거 부실 이력이 있는 기업과 관측 기간 내 첫 부실 기업을 구분해야 한다는 점을 발표의 주요 내용으로 정리하였다. 이번 활동을 통해 모델 구현뿐 아니라 분석 결과를 정확한 재무 언어로 전달하고 그 해석 범위를 설명하는 역량의 중요성을 확인하였다.

**주요 산출물:** SHAP 변수 기여도 그래프, 변수 기여 방향의 안정성 점검 결과, 로지스틱 계수와의 방향 대조표, 기업별 설명 카드 초안, 중간 점검 발표자료.

**본문 출처:** 아래 [6], [8], [13].

## 2. 1~9주차 기록 끝에 추가할 출처 문장

| 주차 | 보고서에 붙일 문장 |
|---|---|
| 1주차 · 선행연구 및 연구 범위 | 부실예측과 표본·시점 설계의 선행연구로 Beaver(1966), Altman(1968), Ohlson(1980), Zmijewski(1984), Shumway(2001)를 검토하였다. 국내 신용평가의 평가 범위는 신용평가사 공개 자료를 참고하였다.[1–5, 11] |
| 2주차 · 분석 설계와 수집 코드 | 기업 식별정보, 공시 접수일, 보고서 구분 및 재무제표 응답 구조는 금융감독원 OpenDART 개발가이드를 참고하였다. 재무정보 공개 시점을 고려하는 설계에는 Ohlson(1980)의 문제의식을 참고하였다.[3, 8] |
| 3주차 · 재무·사건 자료 수집 | 재무제표·감사의견·회생절차 관련 자료는 금융감독원 DART·OpenDART를 사용하였다. 관리종목 등 거래소 공시의 확인에는 한국거래소 KIND를, 시장 변수 구성에는 한국거래소 시세 자료를 활용하였다.[8, 9] |
| 4주차 · 라벨과 데이터셋 구성 | 공시 시점과 사건 시점의 구분 및 표본 선택 편의 점검에는 Ohlson(1980)과 Zmijewski(1984)를 참고하였다. 공시 접수일과 사건 정보의 원천은 DART·OpenDART이며, 부실의 구체적인 정의와 예측 기간은 본 프로젝트의 분석 설계이다.[3, 4, 8] |
| 5주차 · 재무비율과 계정 매핑 | 재무비율은 DART 재무 계정값으로 계산하였으며, 변수 정의와 산업 수준의 비교에는 한국은행 「기업경영분석」 및 ECOS 자료를 참고하였다. 비교 시 표본 범위·집계 방식·금융비용 정의가 다를 수 있음을 고려하였다.[8, 10] |
| 6주차 · 탐색 분석 | 부실 발생 이전의 재무비율 변화 양상을 비교하는 분석에는 Beaver(1966)를 참고하였다. 표와 그림의 수치는 DART 자료를 이용한 본 프로젝트의 자체 계산 결과이며, 사후에 사건군을 구성한 탐색 분석을 조기예측 성능의 증거와 구분하였다.[1, 8] |
| 7주차 · 기준 모델과 평가 | 로지스틱 기반 부실예측에는 Ohlson(1980), 기업의 반복 관측을 고려하는 분석에는 Shumway(2001)를 참고하였다. PR 지표의 해석 근거로 Saito와 Rehmsmeier(2015)를 인용하며, 모델과 지표의 구현 출처는 scikit-learn이다.[3, 5, 7, 12] |
| 8주차 · 부스팅 및 비교 분석 | 부스팅 모델과 확률 보정에는 scikit-learn 구현을 사용하였다. 학습 표본 구성의 편의 점검에는 Zmijewski(1984), 재무·시장 변수 비교에는 Shumway(2001)를 참고하였다. 기존 연구와 표본·사건 정의가 다르므로 직접적인 우열을 주장하지 않았다.[4, 5, 12] |
| 9주차 · SHAP 및 발표 준비 | 변수별 예측 기여도 분석의 방법론 출처는 Lundberg와 Lee(2017)이며, 구현에는 SHAP 소프트웨어를 사용하였다. 설명 카드의 한국어 문장 구성과 검토 절차는 본 프로젝트에서 설계하였다.[6, 13] |

## 5. 작성자 확인 메모 — 제출 본문과 구분

- 이 문서는 기존 W01~W09 활동 기록과 중간발표 내용을 바탕으로 작성했다. 주차별 파일에는 오래된 수치·상태 표시가 남아 있으므로 9주차 본문에 그 수치를 그대로 옮기지 않았다.
- 2차 연구의 최종 PR-AUC, 설명 검사 11.9%→0, 14.2배, 동결 모델·사이트 완성 등 후속 성과를 9주차 수행 내용으로 소급해 넣지 않았다. 실제 수행일과 계획 주차는 구분한다.
- [1]~[5]는 기존 선행연구 검토 문서에 기록된 문헌이다. 전체 원문을 정독했다는 사실까지 이 기록만으로 확인할 수는 없으므로 ‘원문 정독 완료’라고 쓰지 않는다.
- [6]~[7]은 사용 방법을 뒷받침하기 위해 중간발표 자료 작성 과정에서 출처를 보완한 문헌이다. 1주차부터 읽었다거나 해당 논문 때문에 처음 방법을 선택했다고 소급해 서술하지 않는다.
- [12]~[13]은 실제 사용한 소프트웨어의 공식 문서 링크다. 당시 이 문서의 특정 버전을 읽었다는 사실은 확인하지 않았으므로 개발 도구의 출처로 표기한다. 구현 재현에는 실제 실행 환경의 패키지 버전을 함께 남긴다.
- 국내 신용평가 방법론 대조 문서는 공개 자료·검색 요약에 기반한다고 명시되어 있다. 특정 회사의 세부 기준·가중치를 인용하려면 해당 원문과 판본을 추가 확인한다.
- 한국은행의 실제 비교 원자료는 지역별 표였다는 기록이 있다. 보고서에 구체적인 수치를 인용할 때에는 파일명·통계표·연도·지역·집계 방법을 함께 적고, 전국 기준 검산이 완료됐다고 단정하지 않는다.
- 숫자는 출처 문헌의 결과와 연구팀의 자체 결과를 구분한다. 접속일·열람일은 실제 확인한 날짜를 기입하며, 과거 주차의 날짜를 임의로 만들지 않는다.
