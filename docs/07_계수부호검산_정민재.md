## 3. Δ변수의 반대 부호는 오류가 아닙니다

모형에 수준값 `X_t`와 변화량 `ΔX = X_t − X_{t−1}`가 **함께** 들어가 있으므로, 식을 다시 쓰면 다음과 같습니다.

```
β_L·X_t + β_Δ·(X_t − X_{t−1})  =  (β_L + β_Δ)·X_t  −  β_Δ·X_{t−1}
```

올해 수준을 고정한 상태에서 Δ가 크다는 것은 **작년 수준이 낮았다**는 뜻입니다.

| 변수 | β_L | β_Δ | 올해 수준 계수 | 작년 수준 계수 |
|---|---|---|---|---|
| 유동비율 | −0.525 | +0.136 | −0.39 | −0.14 |
| 총자산회전율 | −0.673 | +0.192 | −0.48 | −0.19 |

두 해 모두 음수이므로 **"올해도 작년도 유동성·효율성이 낮으면 위험하다"**는 뜻이 되고, 재무 상식과 맞습니다.
Δ 계수만 떼어 "개선되면 위험하다"고 읽으면 안 됩니다.

> **(이종민 주, 2026-10-10)** 결론은 맞습니다(`features.py:118` 이 차분). 다만 위 표의 −0.39/−0.14 등은
> 표준화 계수를 그대로 더한 값이라 크기가 맞지 않습니다. 원단위(계수 ÷ 표준편차)로는 유동비율 올해 −0.055 · 작년 −0.083,
> 총자산회전율 올해 −0.364 · 작년 −1.067 입니다. 부호 결론은 같습니다 (`docs/10` §3-4).
>
> 재고자산회전율 §4 의 세 검산은 모두 돌렸고 부호·유의성이 유지됐습니다(결측 제외 z 3.45 · 업종 더미 3.30 · log1p 2.95).
> 원인 미확정, 10분위 사건비율 U자. 스냅샷 지문은 같고 수치 차이는 분할 변경 때문이었습니다(§6).

**확인 부탁드릴 것**
- Δ가 **차분(X_t − X_{t−1})**인지 **증가율(%)**인지 — 증가율이면 위 논리는 그대로 적용되지 않습니다.
- 계수가 표준화된 값이라면 "올해 수준 계수"의 크기는 두 변수의 표준편차에 따라 달라집니다. "작년 수준 계수"의 부호(음수)는 그와 상관없이 유지됩니다.

## 4. 재고자산회전율 — 데이터를 다시 봐 주세요 ★

VIF 1.01이라 공선성이 아니고, z = 3.52라 잡음도 아닙니다.
"재고 회전이 빠를수록(재고 관리가 효율적일수록) 위험하다"는 결과는 재무적으로 받아들이기 어렵습니다.

**의심되는 원인**

1. **분모(재고자산)가 0이거나 0에 가까운 기업** — 바이오·IT서비스·지주사처럼 재고가 거의 없는 기업은
   회전율이 극단적으로 커집니다. 이런 기업은 코스닥 소형 적자기업과 겹치므로, 계수가 사실상
   **"재고가 없는 업종 = 위험"**을 잡고 있을 가능성이 큽니다. §3-13에서 업종 쏠림이 규모보다 크다고
   확인한 것과도 연결됩니다.
2. **재고자산 = 0일 때의 처리 방식** — 0으로 나눠 inf/NaN이 된 뒤 학습구간 중앙값으로 대치됐다면,
   결측 여부 자체가 신호로 섞였을 수 있습니다.
3. **극단값** — 윈저라이징·로그 변환 없이 극단값이 계수를 끌고 갔을 가능성.

**요청하는 검산**

- [ ] 재고자산이 0이거나 결측인 관측치를 제외하고 재추정
- [ ] 업종 더미 추가 후 재추정
- [ ] 재고자산 = 0 처리 코드 확인 (inf → NaN → 대치 경로인지)

셋 중 하나에서 부호가 뒤집히거나 유의성이 사라지면 원인이 확정됩니다.

## 5. 참고로 짚을 것

- **이익의현금전환 (영업현금흐름 ÷ 순이익)** — 순이익과 영업현금흐름이 둘 다 음수이면 비율이 양수가 되어
  "이익의 질이 좋은" 기업처럼 보입니다. 부호는 맞지만 적자기업에서는 정의 자체가 해석되지 않습니다.
  변수 정의서에 명시하거나, 순이익이 음수인 구간을 별도로 처리하는 것을 제안합니다.
- **자산증가율 (+)** — 한계기업이 유상증자·CB로 자금을 조달하면 자산이 늘어납니다. 방어 가능한 방향이지만,
  "성장 = 안전"으로 기대하는 청중이 있을 수 있어 발표 때 한 줄 설명이 필요합니다.
- **영업이익률** — VIF 10.49로 기준(10)을 넘습니다. 기존 결론(SHAP 방향이 맞고 로지스틱 계수는 신뢰할 수 없음,
  §3-7)을 그대로 유지하면 됩니다.
