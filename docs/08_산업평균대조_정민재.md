## 요약

- **부채비율 · 유동비율 · ROA**: 전 업종 자릿수(1/3~3배) 통과
- **이자보상배율**: 전산업 기준 통과, 업종별로는 **3개 업종(21 의약품 · 26 전자부품 · 46 도매) 이탈** (한국은행 값의 1/5~1/7)
- 이탈은 **중앙값 vs 합산비율 차이 + 금융원가 정의**로 설명되는 패턴이고, **계산식 오류 징후는 없다**고 봅니다
- 단, 이번 비교에 쓴 한국은행 파일이 **지역별 표(서울 제외)**라서 잠정 결과입니다. 전국 표로 다시 받아 재확인하겠습니다

## 비교 방법

| 항목 | 우리 값 | 한국은행 값 |
|---|---|---|
| 출처 | `2_재무비율_분포.csv`(전산업), `2_업종별_비율중앙값.csv`(업종별) — **대치 전 원본** | 기업경영분석 5.9.2.2 손익 지표 / 5.9.2.3 자산·자본 지표 |
| 집계 | 기업별 비율의 **중앙값** | 업종 **합산비율** (Σ분자 / Σ분모) |
| 표본 | 상장사 | 비상장 포함 영리법인 |
| 단위 | 배수 → ×100 해서 % 로 맞춤 | % |
| 대표값 | — | 기업규모 '종합', 11개 지역 × 2015~2023 값의 중앙값 |

감안할 점:

1. **한국은행 파일이 지역별 표입니다.** 지역이 부산·대구경북·광주전남·대전세종충남·충북·강원·인천·제주·경기·경남·울산 11곳뿐이고 **서울이 없습니다.** 상장사 본사가 서울에 몰려 있어 비교 대상이 왜곡될 수 있습니다(특히 58 출판·SW).
2. **합산비율은 대기업이 좌우합니다.** 수익성 지표(이자보상배율 · ROA)는 한국은행 쪽이 높게 나오는 게 정상입니다.
3. **상장사는 공모자금으로 자본이 두껍습니다.** 부채비율이 낮고 유동비율이 높게 나오는 게 정상입니다.

## 금융원가 분모 — 제 의견

**계산은 유지하고, 정의서에 명시 + 변수명 변경**을 권합니다.

K-IFRS 에서는 금융원가에 이자비용 외에 외환차손, 파생상품평가손실 등이 함께 들어가는 회사가 적지 않습니다. 그러면 분모가 커져 이자보상배율이 과소 추정됩니다. 이번에 벗어난 업종이 외화 노출이 큰 **26 전자부품, 46 도매**라는 점이 이 설명과 맞습니다(21 의약품은 적자 기업 비중으로 설명).

1. 변수명을 `이자보상배율` → **`금융원가보상배율`** 로 바꾸거나, 정의서에 다음을 명시
   > 분모: 금융원가(`ifrs-full_FinanceCosts`). 이자비용 외 외환·파생 관련 손실이 포함될 수 있음
2. 설명 카드에서 이 변수를 "이자를 감당할 능력"으로 서술한다면 위 한계를 함께 적어야 함

## 요청 사항

**업종별 합산비율을 `export` 에 추가해 주실 수 있을까요?**

- 업종 2자리별로 **Σ영업이익 / Σ금융원가**, **Σ당기순이익 / Σ자산총계**, **Σ부채 / Σ자본**, **Σ유동자산 / Σ유동부채**
- 한국은행과 같은 방식이 되어 "중앙값 vs 합산비율" 차이가 제거됩니다. 그러고도 이자보상배율만 크게 벗어나면, 남는 차이가 곧 금융원가 정의 효과라고 볼 수 있습니다
- 원자료 열 이름을 제가 몰라서 직접 넣기 어렵습니다

- 그런데 합산으로 맞춰도 **제조업 대부분이 0.3~0.5배**에 모인다(24 1차금속 0.31 · 28 전기장비 0.32 · 29 기타기계 0.33 은 1/3 경계 바로 아래).
  특정 업종이 아니라 **전반적으로** 낮다 — 한국은행 이자보상비율의 분모는 이자비용이고 우리는 금융원가(외환·파생 손실 포함 가능)라는
  정의 차이와 맞는 패턴이다. 표본 차이(비상장 포함, 서울 제외 지역표)도 남아 있어 확정은 전국표 재비교 후.
- 정의서 반영: 설명 카드 문장에 "(금융원가 기준)"을 붙였다. 변수명 변경(`금융원가보상배율`)은 보고서 표기와 함께 정할 것.
- 다른 비율: 부채비율·ROA·유동비율은 합산으로 바꿔도 대부분 자릿수 안. 30 자동차·58 출판·SW 는 합산에서 대형사 영향이 커 배수가 2배 이상으로 커진다.
