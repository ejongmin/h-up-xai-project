# 최종보고서 골격 (14주차 작성, 지금은 자리만 잡아둔다)

분량 목표 25~35쪽. 성능 수치가 아니라 **4절과 5절이 이 보고서의 본론**이다.

1. **문제 설정** — 왜 정확도가 아니라 수용성인가 (1.5쪽)
2. **데이터** — 사건 정의, 제외 규칙, 시점 정합, 표본 구성표, 사건 비율의 연도별 추이 (5쪽)
   - 여기에 A-1~A-3 개정 사항을 그대로 싣는다. 실수를 발견하고 고친 기록이 방법론의 신뢰를 만든다.
3. **모델과 성능** — 기준/앙상블, PR-AUC와 신뢰구간, 민감도 3종 (5쪽)
   - 정확도는 싣지 않는다. 대신 사건 비율 대비 몇 배인지로 말한다.
4. **설명과 검증** — SHAP 안정성, 삭제 검사(충실도), 설명 카드, 오분류 사례 분석 (8쪽)
5. **담기지 않는 정보** — 사건 기업 공시 원문 분석, 목록표, 변수 1개 추가 실험 (6쪽)
6. **한계** — 표본 부족의 정량적 서술, 일반화 가능 범위의 명시적 한정 (2쪽)
7. **진로 탐색 결과** — 모델 개발 직무 vs 리스크 심사 직무, 판단 근거와 로드맵 (3쪽)
8. 부록 — 코드 저장소, 재현 절차, 오분류 사례 기록지

> **6장에 반드시 넣을 것**: 실무자 검증을 하지 않았으므로 "이 설명이 실무에서
> 받아들여진다"는 주장은 이 보고서의 범위 밖이다. 확인한 것은 충실도까지다.

## 쓰면서 지킬 것

- 범위를 넘는 일반화 금지. "국내 상장사 · 2016~2025 · 감사의견/회생 정의" 밖으로 말하지 않는다.
- 평균만 보고하지 않는다. 사례별·평가자별 분포를 같이 싣는다.
- 실험마다 표본 수와 탐지 가능한 최소 효과크기를 밝힌다.
- 버전 정합: 본문의 모든 수치는 어느 코드 커밋·어느 데이터 스냅샷에서 나왔는지 표기한다.
