# 재평가 사전 고정 (2026-10-10)

데이터 오류 수정과 분석 대상 변경 후 결과를 다시 계산하기 **전에** 기준을 적어 커밋한다.
아래 기준은 재계산 결과를 보고 바꾸지 않는다. 바꾸면 별도 실험으로 따로 보고한다.

배경: 외부 검토 결정 — 주 분석을 '관측 기간 내 첫 부실'로, 공시 단위 오류는 원자료 대조 후 원인 단계에서 수정,
학습 라벨의 관측 기간과 검증 시작의 겹침도 재평가 전에 처리.

---

## 1. 분석 대상

| 구분 | 정의 | 위상 |
|---|---|---|
| **관측 기간 내 첫 부실** | 기준시점 T 까지 **관측된** 부실 사건이 없는 기업-연도 | **주 분석** |
| 반복 부실 | T 이전에 관측된 사건이 있는 기업-연도 | 보조 분석 |
| 전체 | 둘을 합친 것 (기존 결과와 비교용) | 보조 분석 |

- "관측된 사건" = `events.csv` 의 사건(감사의견 비적정·회생절차 개시, 2015-01 이후 공시). 그 기업의 **첫 사건일 ≤ T** 이면 반복 부실.
- 2015년 이전 이력은 보이지 않는다. 그래서 이름을 '첫 부실'이 아니라 **'관측 기간 내 첫 부실'**로 쓴다.
  과거 이력 누락이 성능을 어느 방향으로 바꾸는지는 확정할 수 없다고 적는다.
- **집계 단위는 기업-연도 관측치로 통일한다.** 기업 수를 말할 때는 "고유 기업 N곳"으로 따로 표기한다.

## 2. 데이터 오류 처리 기준

원칙: 일괄 삭제·추정 배수 나눗셈을 하지 않는다. **같은 회사의 다른 공시로 확인된 경우에만** 고친다.

1. **단위 전환 확인** — 같은 회계연도 자산총계는 그 해 사업보고서(당기)와 다음 해 사업보고서(전기)에 두 번 공시된다.
   두 값의 비가 10³ 또는 10⁶ 의 ±1% 안이면 두 보고서 사이에 **단위가 바뀐 것**으로 확인한다.
2. 단위가 같은 연속 보고서를 한 구간으로 묶고, **가장 많은 연도를 차지하는 구간을 기준 단위**로 한다(동률이면 자산 1천억~600조 원 범위에 드는 구간).
   다른 구간의 **금액**(자산·매출 등)을 정확히 10ᵏ 로 환산한다.
3. **비율 변수는 바꾸지 않는다.** 분자·분모가 같은 보고서에서 오므로 단위가 상쇄된다(확인: 오류 보고서 안에서 BS·IS 가 같은 배율).
   영향을 받는 것은 **로그자산, 자산증가율, 매출증가율**뿐이며 수정 후 다시 산출한다.
4. **확인할 수 없는 불일치**(같은 연도 두 공시가 10배 넘게 다르지만 10³·10⁶ 이 아님, 또는 비교할 다음 해 보고서가 없음) →
   그 기업-연도의 **로그자산·증가율을 결측** 처리하고 비율은 유지한다.
5. **자산총계 ≤ 0** (빈 재무제표 응답) → 그 기업-연도의 **재무 변수 전체를 결측**으로 한다.
   0 으로 채워진 응답에서 "영업손실 아님" 같은 이진 변수가 거짓으로 만들어지기 때문이다.
6. 증가율의 분모가 0 이면 결측(무한대 금지).
7. 수정 내역은 `results/data_fix/단위수정_내역.csv` 에 행 단위로 남긴다.

## 3. 라벨 관측 기간과 검증 시작의 겹침 (엠바고)

- 문제: 학습 행의 라벨은 T 이후 400일의 사건으로 정해진다. 2021년 공시 학습 행의 라벨 창은 2022년(검증 구간)까지 이어져,
  **검증 시점에는 알 수 없던 사건**으로 학습했다(2,101행, 라벨 사건 25건이 검증 시작 이후 발생).
- **규칙**: 검증 단계의 학습 표본은 `T + 400일 < 검증 구간 첫날(1월 1일)` 인 행만 쓴다.
  롤링 오리진의 각 폴드에도 같은 규칙을 적용한다.
- **최종 모델(평가 구간용)은 학습 구간 전체**로 학습한다 — 학습 구간 라벨 창은 평가 시작(2024년) 전에 모두 끝난다(검사로 확인).
- 정제 기준(윈저라이즈 경계·대치값)은 검증 단계 학습 표본에서 계산한다.

## 4. 모델 설정 (바꾸지 않는다)

- 특성: 재무 27개 + 결측 더미. 과거 사건 여부는 **특성으로 넣지 않는다**(분석 대상을 가르는 데만 쓴다).
- 모델: 기존 앙상블(HistGB, `class_weight="balanced"`), 순위는 비보정 · 표시 확률은 isotonic 보정본.
- 학습 표본: 두 집단(첫 부실·반복) **모두**로 학습한다. 첫 부실 집단만으로 다시 학습하는 것은 **별도 실험**이다.
- 하이퍼파라미터·변수 집합·임계값 정의 변경 없음.

## 5. 재평가

- 평가 구간(2024~2025)을 **1회** 다시 연다. 이름은 "데이터 오류 수정 후 재평가". 완전히 새로운 독립 검증이 아니다.
- 보고: 주 분석(관측 기간 내 첫 부실) → 보조(반복, 전체) 순. 기존 결과와 수정 결과를 **나란히** 싣고 변경 이유를 적는다.
- 지표: PR-AUC(기준선 병기, 부트스트랩 1,000회 95% CI), 재현율@정밀도0.3, 상위 1·2·5·10% 표.
- **평가 결과를 보고 추가 튜닝하지 않는다.**
