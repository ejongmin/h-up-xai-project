# 사용성 점검 계획 — 비전문가가 모델 결과를 이해하고 근거를 찾는 데 도움이 되는가

작성 2026-11-01. 실행 전 계획. **탐색적 사용성 점검**이며 투자 판단의 정확성이나 실무 효과를 입증하는 실험이 아니다.
실무자 평가는 범위에서 제외했다(docs/15). 여기서는 동료 학생(비전문가)을 대상으로 한다.

## 1. 질문

같은 기업 자료를 볼 때, **위험 순위와 원문만** 받은 경우와 **기업 위험 검토 도구 전체**(설명 카드 · 공시 재무비율 · 검사·주의 표시 · 원문)를 받은 경우에
① 위험 요인을 찾고 ② 그 근거 수치를 찾고 ③ 추가로 확인할 공시 항목을 고르는 데 걸리는 시간 · 정답률 · 잘못 이해한 부분이 어떻게 다른가.

## 2. 조건

| 조건 | 보는 것 | 주소 |
|---|---|---|
| A. 순위+원문 | 위험 순위, 공시 기준월, DART 최초 공시 원문 링크 | 로컬판 `site/index.html?mode=score` |
| B. 도구 전체 | A + 설명 카드 · 공시 재무비율 · 검사·데이터 주의 · 더 확인할 곳 | 로컬판 `site/index.html` |

'위험 점수만' 주면 과제 2(근거 수치 찾기)를 할 방법이 없으므로, A 에도 원문 링크를 준다 — 비교 대상은 '원문을 직접 읽기' 대 '도구가 정리해 준 근거'다.
두 조건 모두 '이후 실제 사건' 펼치기는 열지 않게 안내한다.

## 3. 사례와 배정 (`scripts/usability_kit.py`)

- 사례 4개: 평가 구간 첫 부실 대상 중 설명 검사 통과, 위험 요인 2개 이상, 업종이 서로 다르고 순위가 비슷한(150위 안팎) 기업. 시연 사례는 쓰지 않는다.
  현재 선정: #327(기타) · #052(정보통신) · #165(제조) · #428(도소매).
- 참가자마다 4개를 한 번씩 본다 — 2개는 A, 2개는 B. **사례 묶음과 조건 순서를 4가지로 돌려** 기억·학습 효과와 사례 난이도를 섞는다 (`results/v2/usability/배정표.csv`).
- 권장 인원 8명(배정 한 바퀴의 2배). 그 이하면 배정 순서대로 자른다.

## 4. 과제 (사례마다 같은 세 개)

1. 이 기업의 위험을 높인 재무 요인 두 가지를 적으세요.
2. 1번 요인 각각의 근거가 되는 재무 수치를 찾아 적으세요.
3. 이 기업에 대해 사업보고서에서 추가로 확인해야 할 항목 하나를 고르고 이유를 적으세요.

## 5. 기록과 채점 (`results/v2/usability/기록양식.csv`)

| 측정 | 방법 |
|---|---|
| 완료 시간 | 과제별 초 (진행자가 잰다) |
| 과제 1 정답 | 모델이 위험을 높였다고 본 요인(카드의 위험 요인 최대 4개) 중 몇 개를 맞혔나 (0~2) |
| 과제 2 정답 | 원문 수치와 반올림 범위 안에서 일치하는 개수 (0~2) |
| 과제 3 적절 | 정답표의 예시(요인별 '더 확인할 곳' · 데이터 주의)와 같은 취지면 1 — 채점 기준은 점검 전에 정답표로 고정 |
| 잘못 이해한 부분 | 진행자 관찰 기록 (예: 순위를 확률로 읽음, 위험을 낮춘 요인을 높인 요인으로 읽음) |
| 주관 평가 | 이해 쉬움 · 근거 확인 쉬움 (1~5) |

정답표(`data/usability/정답표.csv`)에는 기업명과 원문 링크가 있어 **커밋하지 않는다**. 과제 1 의 '정답'은 모델의 판단 근거다 — 재무적으로 옳은 위험 요인이라는 뜻은 아니며,
조건 A 에서는 참가자가 원문만 보고 모델의 근거를 추측해야 한다는 점을 해석할 때 감안한다.

## 6. 진행

1. 동의: 익명 기록, 언제든 중단 가능, 개인 정보 수집 없음. 화면의 기업명은 점검 목적으로만 보여준다는 점을 알린다.
2. 연습 1개(시연 사례 #381)로 화면 사용법만 설명한다 — 과제 정답은 알려주지 않는다.
3. 배정표대로 블록 1 → 블록 2. 블록 사이에 조건이 바뀐다는 것만 알린다.
4. 끝나고 주관 평가 두 문항과 자유 의견.
한 사람에 20~25분.

## 7. 분석과 보고

- 참가자 안에서 A 와 B 를 비교한다(같은 사람이 두 조건을 모두 본다). 과제별 중앙 시간 · 정답 수 · 오해 유형을 표로 보고한다.
- 인원이 적어 **통계적 유의성을 주장하지 않는다.** 차이의 방향과 개별 오해 사례를 기술한다.
- 결과가 B 에 불리해도(예: 카드 문장을 사실로 과신) 그대로 보고하고, 그것이 설명 문구 개선 과제다.
