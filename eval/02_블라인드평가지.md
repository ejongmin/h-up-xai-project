# 블라인드 평가 도구 (11주차 제작 / 12~13주차 사용)

## 설계 원칙

평가는 반드시 **두 단계로 나누어** 진행한다. 모델 결과를 먼저 보여주면 실무자의 판단이
그쪽으로 끌려가고(앵커링), 그 순간 이 프로젝트의 핵심 질문이 사라진다.

- **1단계**: 기업명·연도를 가린 재무제표만 제시 → 실무자가 먼저 판단
- **2단계**: 모델 확률 + 설명 카드 제시 → 동의 여부와 납득도 평가
- 1단계 응답을 제출(또는 구두 확정)하기 전에는 2단계 자료를 절대 노출하지 않는다.

## 사례 10건 구성

| 구분 | 건수 | 선정 기준 |
|---|---|---|
| 실제 사건 발생 · 모델도 고위험 | 3 | 모델 확률 상위, 사건 발생 |
| 실제 정상 · 모델도 저위험 | 3 | 모델 확률 하위, 사건 없음 |
| 실제 사건 발생 · 모델은 저위험 (미탐) | 2 | **가장 중요한 사례군** |
| 실제 정상 · 모델은 고위험 (오탐) | 2 | 실무자가 왜 괜찮다고 보는지 확인 |

- 업종과 자산규모가 한쪽에 몰리지 않게 배분한다.
- 제시 자료: 최근 3개 연도 요약 재무제표(재무상태표·손익계산서·현금흐름표 주요 계정) + 산출 재무비율표.
- 감사의견, 계속기업 불확실성 주석, 기업명, 연도, 업종 상세는 **가린다**(업종은 대분류만).

## 채점·집계 규칙

| 지표 | 계산 |
|---|---|
| 실무자–모델 일치율 | 1단계 4~5점 = 고위험으로 이진화 후 모델 상위/하위와 비교 |
| 실무자–실제 정확도 | 1단계 판단 vs 실제 사건 (모델과 같은 기준으로) |
| 설명 납득도 | 문항 6 평균 및 **사례별 분포**(평균만 보고하지 않는다) |
| 인용 가능성 | 문항 8 '가능' 비율 |
| 근거 일치도 | 문항 2의 근거 3개와 설명 카드 요인의 교집합 비율 |

평가자 6명 · 사례 10건이면 관측치는 60개다. **이 표본으로 통계적 유의성을 주장하지 않는다.**
사례별·평가자별 응답을 그대로 싣고, 해석은 정성적으로 한다.
