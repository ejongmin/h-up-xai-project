# 모델–실무자 판단 갭 분석 (13주차)

일치한 사례가 아니라 **갈린 사례**가 이 프로젝트의 결과물이다.

## 분류

| 유형 | 정의 | 물어야 할 것 |
|---|---|---|
| 유형 1 | 모델 고위험 · 실무자 저위험 · 실제 정상 | 모델이 과민한 지점. 어떤 변수가 오작동했나 |
| 유형 2 | 모델 저위험 · 실무자 고위험 · 실제 사건 | **실무자가 보고 모델은 못 본 것.** 가장 중요 |
| 유형 3 | 둘 다 저위험 · 실제 사건 | 재무제표의 구조적 한계 |
| 유형 4 | 둘 다 고위험 · 실제 정상 | 부실 신호와 회복 사이의 구분 실패 |

## 유형 2 전용 기록지 (사례마다 1장)

```
사례 번호:              실제 사건: (감사의견 / 회생 / 없음)
모델 확률:              모델 상위 기여 변수:
실무자 판단(6명 분포):
실무자가 든 근거 중 모델 변수에 없는 것:
그 정보가 공시에 존재하는가? (존재 / 존재하나 비정형 / 미존재)
변수화 가능성: (가능 - 추가 파싱 필요 / 가능 - 유료 데이터 필요 / 불가)
```
